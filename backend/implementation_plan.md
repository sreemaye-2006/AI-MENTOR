# Implement Study Plan Tracking & Roadmap Resources

This plan details the technical changes required to implement task tracking inside the Study Plan and displaying review material inside the Roadmap.

## User Review Required
> [!IMPORTANT]
> The database schema for `StudyPlan` and `CareerRoadmap` will need slight updates to support task completion states and linking resources to specific roadmap steps. Please review the proposed changes below to ensure they meet your expectations.

## Proposed Changes

### Backend Updates

#### [MODIFY] `models/StudyPlan.js`
- Change `dailyTasks` from an array of strings `[String]` to an array of objects to track completion: `[{ task: String, completed: { type: Boolean, default: false } }]`.

#### [MODIFY] `controllers/studyController.js`
- Update the AI response parsing logic to map the array of task strings into the new object structure with `completed: false`.
- Create a new endpoint `markTaskComplete(req, res)` that takes a `week` and `taskId`, sets it to `true`, and recalculates the total `progress` percentage of the study plan.

#### [NEW] `routes/studyRoutes.js`
- Add a new `PUT /:id/task` route connected to the `markTaskComplete` controller function.

#### [MODIFY] `controllers/roadmapController.js`
- Update the Lyzr AI prompt to include `resources: [{ title: "...", url: "..." }]` directly inside each `roadmapSteps` object, so that every step has specific review material tied to it.
- Ensure the `CareerRoadmap` model and controller parsing logic accommodates this new field inside `roadmapSteps`.

### Frontend Updates

#### [MODIFY] `services/studyServices.js`
- Add an API function `completeTask(planId, weekIndex, taskIndex)` to call the new backend PUT endpoint.

#### [MODIFY] `pages/StudyPlan.jsx`
- Replace the "Start" button logic with a dropdown/accordion.
- Clicking the topic card will expand it to reveal a checklist of `dailyTasks`.
- Checking a task will call the `completeTask` API, update the local UI state, and immediately reflect the change in the global "Today's Goal" progress bar.

#### [MODIFY] `pages/Roadmap.jsx`
- Modify the "Review Material" button. When clicked, it will open a dropdown or a small modal displaying the `resources` (with clickable links) specifically generated by the AI for that step.
